# 프론트엔드 분석

| 대상 | 방법 | 추출 |
|------|------|------|
| 라우트 | app/ 또는 pages/ 파일 구조 | URL → Page 매핑 |
| API 호출 | hooks/, lib/api/ 탐색 | 백엔드 API → 프론트 훅 |
| 컴포넌트 | components/ 탐색 | 공통/도메인별 |
| 상태 관리 | stores/, contexts/ 탐색 | 전역 상태 목록 |
| 타입 | types/, interfaces/ 탐색 | API 응답 타입 정의 |

## 출력 구조 (CONTEXT-MAP)
```
## 도메인별 기능-라우트-파일 매핑
| 기능 | 라우트 | 파일 매핑 |

## API 연동 매핑
| 백엔드 API | 프론트 훅 | 사용 페이지 |

## 컴포넌트 매핑
| 도메인 | 컴포넌트 | 사용 페이지 |

## 기능→파일 가이드
| "이런 기능이면" | 생성할 파일 |
```
